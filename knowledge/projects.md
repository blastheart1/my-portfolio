# Key Projects

## Pilates With Bee
An online Pilates clinic platform with headless CMS and automation.
- Built for a fitness instructor to manage classes, bookings, and content
- Uses Next.js, Sanity CMS, and automated workflows

## ResumeAI
AI-powered resume analysis web app with skill matching.
- Analyzes uploaded resumes and matches skills to job descriptions
- Uses OpenAI API for natural language processing

## AI Chat with LM Studio
Full-stack AI chat application with local LLM and global access.
- Integrates LM Studio for running models locally
- Full-stack React + Node.js architecture with global access via ngrok

## This Portfolio Chatbot
The very chatbot you're talking to — built by Luis.
- Hybrid TensorFlow.js (client-side classification) + AI API fallback
- Learns from conversations, stores examples in Neon DB
- Custom knowledge mounting from .md files
- Supports Claude and OpenAI as interchangeable AI providers
